# Корень ловит словоформы: "сук" → "сука", "суки", "суке".
# Двусмысленные короткие корни не добавлены во избежание ложных срабатываний
# (например "манда" совпала бы с «мандарин», "хрен" — с овощем, "очко" — с
# «очки», "нигер" — с «Нигерия», "жид" — с «жидкий», "хач" — с «хачапури»).
# "урод" может задеть «уродиться». Админы расширяют через /addword.
